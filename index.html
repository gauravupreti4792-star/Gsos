Check your download on Windows (PowerShell):

Get-FileHash .\GSOS.iso -Algorithm SHA256

The result must match the SHA-256 above. The file is hosted on the Internet Archive.

What you need

  • A 64-bit computer (Intel or AMD) with 4 GB of memory or more.
  • A USB stick of 8 GB or more.
  • An internet connection for the Store and updates.

Install in four steps

  1. Download the ISO file above and check the SHA-256.
  2. Make the USB stick. Open Rufus, choose the ISO, and when asked pick DD Image mode.
  3. Start from the USB. Restart the computer, press the boot-menu key (often F12, F2 or Esc) and choose the USB stick.
  4. Try it, then install. Explore GSOS from the stick. Use the Install GSOS icon on the desktop when you are ready.
Important: choosing "Erase disk" in the installer deletes everything on that drive. Back up your files first, or try GSOS in a virtual machine.

Questions

Is GSOS free?

Yes. You can download, try and share it for free.

What is it built on?

GSOS is powered by Linux and uses the KDE Plasma desktop. The look, the Store and the setup are GSOS's own.

Will all my Windows apps work?

Many do, but not all. Office, WinRAR and Adobe Reader work in our tests. Some apps, such as certain Adobe programs and games with anti-cheat, may not.

Is it safe to try?

Starting from the USB stick does not change your computer. Only the installer writes to your drives, so back up first.

Where is the source code?

The build recipe and files are on our GitHub page. GSOS includes open-source software, each under its own license.
